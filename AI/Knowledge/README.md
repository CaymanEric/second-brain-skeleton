# AI / Knowledge

Reference notes agents consult:

- `Vault Index.md`: a table of "if the request is about X, look in Y, start at
  note Z," so retrieval is targeted instead of a full scan.
- `Agent Roster.md`: the six Claude Code subagents, what each is for, what it
  must not be used for, and which model it runs on. Five of six are read-only.
- `Vault Privacy.md`: what may leave the machine (nothing, unless authorized
  for that request), what is never read or echoed, and the minimum-context rule.
- `Claude Code Gotchas.md`: technical traps on this machine, appended to
  whenever a correction was needed.
- `Prompt Engineer Workflow.md`: reusable prompt and spec patterns.
