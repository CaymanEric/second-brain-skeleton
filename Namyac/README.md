# Namyac

The local voice assistant. `Namyac.md` is its operating rules (who I am,
writing style, vault rules, when to escalate to Claude, never run anything on
the PC without approval, never talk over me). `Namyac Dashboard.md` and
`Jarvis Operating Page.md` record what has been built, what was verified, and
what is parked.

Vault rules for the assistant: never rewrite an existing note, append only
under a heading with its name; file new notes in the closest existing folder
and use `Inbox/` when unsure; link only to real notes.
