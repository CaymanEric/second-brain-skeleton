# Reels

One note per Instagram reel, about 33 notes, whatever the subject. A reels
agent watches `_Reel Inbox.md` for new links, writes each note here, and adds a
line to `Instagram Reels Lessons.md` between two marker comments. Everything
outside the markers is hand-written and never touched by the agent.

AI-related reels are also linked from `AI Lessons/AI Lessons.md`. Same summary
rules as YouTube notes: keep every setting, hotkey, name, number, step, and
caveat, with the reel URL and creator handle so it can be checked.
