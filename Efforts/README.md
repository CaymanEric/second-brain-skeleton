# Efforts

Active projects. This is the output side of the vault: `AI Lessons/` is what I
take in, this is what I make.

`Efforts.md` is the hub. It lists each project with its recorded state and links
to the project note, which owns the detailed status and next actions. A backlog
section holds things that are not yet a project note.

Weekly check: for each active Effort, what is the one thing blocking it right
now? Do that, not the easier thing next to it.
