# Atlas

Ideas and concepts, one per note, in my own words. About 110 notes.

Every note links back to the source it came from (a video, a course lesson, a
person). Source summaries stay in `AI Lessons/`; this folder is where the
reusable idea gets pulled out so it can be linked, reused, and argued with.

`Atlas.md` is the hub note. It groups the notes by theme (mental models,
working with AI tools, judging sources, learning) with a one-line gloss each.

## Rules

- One idea per note. If it is still the source's phrasing, it is not an Atlas
  note yet.
- Link every idea back to its source, both ways.
- Tag by output and status (`#draft`, `#research`, `#published`), not by topic.
- Titles are short imperative phrases with no punctuation beyond spaces, for
  example `Dry Run Before Writes` or `Rank Don't Eliminate`.
